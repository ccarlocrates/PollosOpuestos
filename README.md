# 🍗 PollosOpuestos - App Móvil de Fidelización y Carta Digital

[![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat&logo=kotlin&logoColor=white)](https://kotlinlang.org/)
[![Android](https://img.shields.io/badge/Android-3DDC84?style=flat&logo=android&logoColor=white)](https://developer.android.com/)
[![Status](https://img.shields.io/badge/Status-Prototype-orange)](#)

Prototipo de aplicación móvil nativa para Android diseñada para un negocio de restauración especializado en hamburguesas y pollos a la brasa. La aplicación está enfocada en mejorar la experiencia del usuario mediante la consulta de catálogo, información nutricional y la fidelización de clientes.

---

### 🚀 Características Principales

- 🍔 **Carta Digital Interactiva:** Exploración completa del menú con categorías (hamburguesas, pollos a la brasa, complementos, bebidas).
- ⚠️ **Información de Alérgenos e Ingredientes:** Fichas detalladas de cada producto para garantizar la seguridad alimentaria de los clientes.
- 🎯 **Sistema de Fidelización y Puntos:** Acumulación y consulta de puntos canjeables por promociones en el establecimiento.
- 🏷️ **Ofertas y Descuentos Exclusivos:** Sección dedicada a cupones y promociones activas.
- 🔔 **Notificaciones Push y Publicidad:** Canal directo de comunicación para anunciar novedades, eventos y ofertas especiales.

---

### 🛠️ Tecnologías y Herramientas

- **Lenguaje:** Kotlin
- **Plataforma:** Android SDK
- **Interfaz de Usuario:** XML Layouts / Material Design Components
- **Arquitectura:** Patrón orientado a componentes Android (Activities, Fragments, Adapters)
- **Notificaciones:** Android NotificationManager / Firebase Cloud Messaging (FCM)
- **IDE:** Android Studio
